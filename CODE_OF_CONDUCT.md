# Code of Conduct

EAOS follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- **Be respectful and welcoming**, whatever someone's experience, language, background or identity.
- **Discuss the work, not the person.** Disagree with evidence, as EAOS itself does.
- **No harassment, insults or personal attacks**, in issues, pull requests, reviews or anywhere the project lives.
- **Help newcomers.** Many people using EAOS are not developers; answer them in plain words.

## Enforcement

Report unacceptable behaviour privately to the maintainers through the repository owner's GitHub profile. Every report
is reviewed and kept confidential. Maintainers may remove, edit or reject contributions, and may ban anyone whose
behaviour breaks this code.
