# EAOS roadmap

Where EAOS is going: from today's EAOS to the tool of `docs/NORTH-STAR.md`, which turns a beginner's or vibe-coded
project into a clean, professional product that can ship, behaviour proved unchanged, by running a structural clean-up
round on it. The plan was started again from zero on 2026-11-10; the milestones before it (M-1 to M18, versions 0.0.71
to 0.0.92) are told in `CHANGELOG.md`. Each phase ends with one version and its numbers in `docs/METRICS.md`; a
phase counts as done only when its exit test is measured.

| Phase | What it builds |
|---|---|
| P0 The reset | the direction, the full target and this plan |
| P1 The exam bench | projects never seen, one with a known answer; the round's table measured before and after, judged outside EAOS |
| P2 Measurement | every number of the round, by tools that parse the code; dead code found precisely; the bounds 400 / 50 / 10 / 5 / 120 |
| P3 The safety net | proof that nothing changed, built where none exists: own tests as a gate, pixel-identical screens, fixed clocks, frozen data, recorded API answers, output fingerprints, planted defects |
| P4 Guards in the person's repository | ceilings that only go down, in their own lint, hook and CI, working without EAOS |
| P5 The map | every file's feature and layer, or split, from each symbol's real users |
| P6 The round driver | the charter, phases on branches, numbered steps, reports, the person's approval |
| P7 Health and dead code | swallowed errors, floating promises, skipped tests and dead code to zero, banned |
| P8 Structure | moves by tool, mixed files untangled, doors between features, the big doors and barrels gone |
| P9 Consolidation and limits | the formatter proved layout-only, near copies merged, files and functions split verbatim |
| P10 Code only | comments that explain code, no development files or customer names in what ships, data out of the code |
| P11 Agents and the guide | many assistants on owned files, and a guide kept true to the code |
| P12 The full exam | the whole round on the exam projects, judged outside |
| P13 EAOS on itself, then Python | EAOS cleaned by its own round; the round for Python projects |
