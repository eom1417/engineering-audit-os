1. **M12.T1**: ثبّت بروتوكول التقييم والحالات والعتبات مبكرًا، قبل ضبط الخوارزميات على نتائج الأمثلة.
2. **M4.T1**: احصر قدرات المسار القديم قبل ترحيله أو حذف أي قدرة.
3. تابع `--next`: المراحل M5 وM6 وM8 تضم مهام مستقلة يمكن تنفيذها تباعًا. ترتيب القائمة لا يطلب تشغيل وكلاء متوازيين.
4. **M10**: أكمل ربط القرار بالتنفيذ والتحقق والإغلاق؛ بعض مهام M7 تنتظر نتيجة هذه المرحلة.
5. **M11**: أكمل فهم التدفقات وتخصيص البطاقات واتساق المخرجات واللغة.

المرجع الملزم للترتيب هو `task.depends_on`، وليس رقم المرحلة وحده. لا يُفترض تنفيذ M4 كاملة قبل بدء أي M5، لأن ملكية المصنوعات في M4 تحتاج عقدًا تبنيه M5. أُزيل أيضًا الدور بين M7.T2 واختباره في M7.T3.

## تعريف الإنجاز

لكل مهمة سجل مستقل `docs/task-results/<ID>.json` يتضمن:

- `task_id` و`source_revision`، مع وصف التعديلات غير الملتزم بها إن وجدت.
- `commands`: argv أو الأمر، cwd، وقت التنفيذ، exit_code، ومسار السجل الفعلي.
- `acceptance_cases`: كل شرط، نتيجته pass/fail/blocked، والدليل الذي يسنده.
- `artifacts`: الملفات المسلمة وروابطها؛ `limitations`: ما لم يُختبر أو تعذر.
- `verdict`: pass/fail/blocked. مهمة التقييم المستقل تحتاج أيضًا هوية المراجع ودليل استقلاله؛ أسماء وهمية أو نتائج scripted لا تحقق ذلك.

لا تضع نتيجة pass عند وجود شرط قبول لازم محجوب. عدم اكتمال شرط مستقل لا يمنع إنجاز عمل آخر لا يعتمد عليه. لا توجد آلية في هذه الوثائق تشغّل العمل في الخلفية؛ النموذج المنفذ يتابع المهام أثناء جلسته.

## مراجع نثق بها وكيف نستخدمها

- **ما يجب أن يقدمه المنتج:** OUTPUT-SPEC وQUALITY-AND-EVALUATION والمثال المرجعي؛ المثال يحدد المستوى ولا يثبت أن المنتج يحققه.
- **ما ينفذه الكود اليوم:** ملفات Python واختباراتها ومراحل pipeline؛ إذا خالف الكود وصفًا قديمًا فسجّل التباين وأعد قياس السلوك.
- **الأنظمة الخارجية:** upstreams/registry.yaml يحدد النسخة والالتزام وطريقة الدمج. اقرأ نسخة المصدر المحلية المطابقة، ثم fixture عقد المحول. لا تعتمد على اسم محرك أو عدد نجومه كدليل صحة.
- **الملف المخطط إنشاؤه:** البطاقة تذكر المهمة المنتجة له صراحة. غيابه قبل انتهاء prerequisite طبيعي؛ لا تختلق محتواه.

## ما لا يجوز ضمانه

الخطة قابلة للتسليم لنموذج برمجي كفء، لكن لا توجد خطة تجعل أي نموذج ينجح تلقائيًا. اكتمال الكود، واجتياز الاختبارات، وصحة الاستنتاجات، وفائدة التقرير للمستخدم أربعة أحكام مختلفة. M12 تختبر الأخيرين؛ غياب مزود حي أو مراجع مستقل يجعل تلك المهام محجوبة، ولا يبرر إعلان أن «تقرير الأحلام» تحقق.
