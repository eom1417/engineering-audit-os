## خطوات التنفيذ

1. دفعة لكل حكم، التزام مستقل: replaced أولًا (الأقل خطرًا)، ثم delete، ثم migrate، وkeep بلا تغيير
2. مع كل أمر محذوف: احذف اختباراته أو حوّلها لتغطي البديل الحديث
3. سجّل كل حذف في CHANGELOG مع اسم البديل — لا حذف صامت
4. بعد كل دفعة: شغّل بوابة العبور كاملة
5. قدّم aliases وإشعار ترحيل حيث يوجد مستخدم قديم؛ لا تجعل حذف أسماء أوامر من --help معيار نجاح. تحقق من كل قدرة migrate وإعادة قراءة سجل قديم دون تغيير bytes.
