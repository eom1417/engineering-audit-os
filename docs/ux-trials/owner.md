# تجربة المالك (X7، المهمة NS27.T5)

المالك (غير تقني) يجرّب EAOS على جهازه (MacBook Air) من الصفر، بالدليل وحده (`docs/GUIDE.md`)، داخل Claude Code.
تُسجَّل هنا كما جرت: ما كتبه، وما رآه، وأين تعثّر، والمدة. التجربة تنجح إن وصل إلى فرع إصلاحات مسلّم في مشروعه بلا
مساعدة، وقرأ التقرير وفهمه.

## الخطوات

**الطريق الأول: فحص مشروع قائم وإصلاحه (chief-ops)**

1. سطر التثبيت في الطرفية.
2. فتح Claude Code في مجلد المشروع.
3. «افحص مشروعي بـ EAOS وأصلح مشاكله».
4. «نعم» للسؤال الوحيد.
5. قراءة التقرير: «افتح لي التقرير».
6. القرار: اعتماد الفرع أو التراجع عنه.

**الطريق الثاني: بناء مشروع جديد من خطة**

1. مجلد فارغ جديد، وفتح Claude Code فيه.
2. «عندي خطة مشروع في هذا الملف: …، ابنه بـ EAOS بأفضل هيكلة».
3. الإجابة عن اختياراته (أو «خذ توصياتك»)، ثم «نعم» للسؤال الوحيد.
4. «افتح لي المخطط» لرؤية الأجزاء والتقنيات وتقدم البناء.
5. القرار في النهاية: اعتماد الفرع الأخير أو التراجع.
