# تجربة المالك (X7)

المالك (غير تقني) يجرّب EAOS على جهازه (MacBook Air) من الصفر، بالدليل وحده (`docs/GUIDE.md`)، داخل Claude Code.
تُسجَّل هنا كما جرت: ما كتبه، وما رآه، وأين تعثّر، والمدة. التجربة تنجح إن وصل إلى فرع إصلاحات مسلّم في مشروعه بلا
مساعدة، وقرأ التقرير وفهمه.

## الخطوات

1. سطر التثبيت في الطرفية.
2. فتح Claude Code في مجلد المشروع (chief-ops).
3. «افحص مشروعي بـ EAOS وأصلح مشاكله».
4. «نعم» للسؤال الوحيد.
5. قراءة التقرير: «افتح لي التقرير».
6. القرار: اعتماد الفرع أو التراجع عنه.
